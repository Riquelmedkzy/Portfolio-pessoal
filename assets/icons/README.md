# Ícones de Habilidades

Os SVGs abaixo vieram do repositório oficial [Simple Icons](https://github.com/simple-icons/simple-icons), versão **[16.36.0](https://github.com/simple-icons/simple-icons/releases/tag/16.36.0)** (tag publicada em 25 de outubro de 2026). Os arquivos foram baixados do diretório `icons/` dessa tag e mantidos sem alteração. A página usa os SVGs locais; não há carregamento de imagens ou ícones por CDN.

O repositório Simple Icons declara [**CC0 1.0**](https://github.com/simple-icons/simple-icons/blob/16.36.0/LICENSE.md) para a coleção, mas isso não substitui a licença individual de cada marca. Conforme o [aviso legal oficial](https://github.com/simple-icons/simple-icons/blob/16.36.0/DISCLAIMER.md), a ausência de uma licença individual no catálogo não significa que o ícone esteja sem restrições. MySQLi não possui ícone próprio na lista usada: a página mostra o símbolo PHP e mantém o rótulo **MySQLi**. React Native usa o símbolo React, com o nome **React Native** escrito ao lado. Os dois arquivos ficam disponíveis localmente para esses usos.

O campo de licença sem informação permanece **não confirmado**; ele não foi tratado como CC0 nem como autorização de uso da marca. A licença declarada para PHP requer atribuição e compartilhamento pela mesma licença; o catálogo declara MIT para o ícone JavaScript. Antes de uma publicação pública, confirme as permissões e regras de marca dos respectivos titulares, especialmente para os nove ícones sem licença individual indicada.
